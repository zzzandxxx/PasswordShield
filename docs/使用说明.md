# 密码盾 · Password Shield

一款本地加密的安卓密码管理 App：生成高强度密码 + 安全保存密码。
所有数据仅保存在手机本机，**不联网、不上传、无任何第三方依赖**。

- 安装包：`PasswordShield-v1.0.apk`（约 80KB）
- 兼容：Android 8.0（API 26）及以上，arm64 / x86 等所有架构（纯 Java 实现，无原生库）

---

## 一、安装到手机

1. 把 `PasswordShield-v1.0.apk` 传到手机（微信/QQ/数据线/网盘均可）
2. 在手机上点击 APK → 系统会提示"未知来源应用"→ 选择**允许**（或到 设置 → 安全 中开启"允许安装未知来源应用"）
3. 安装完成，桌面出现「密码盾」图标

> 安装时会提示签名信息，这是自签名的个人证书，正常现象。

## 二、功能速览

| 模块 | 功能 |
|---|---|
| 生成 | 长度 6~64 可调；大小写 / 数字 / 特殊符号可独立开关；可排除易混淆字符（0O1lI）；实时熵强度显示；点密码区直接复制 |
| 密码库 | 添加/编辑/删除条目（标题、账号、密码、网址、备注）；搜索；展开查看；一键复制密码/账号；密码显示/隐藏 |
| 设置 | 更改主密码；自动锁定（1/3/5/10 分钟/从不）；切后台立即锁定；导出加密备份；导入备份；清空所有数据 |
| 安全 | 打开 App 需输入主密码解锁；无操作自动锁定；复制到剪贴板的密码在系统剪贴板预览中自动遮蔽（Android 13+） |

## 三、安全设计

- **主密码** → PBKDF2-HMAC-SHA256 运算 **25 万次** 派生 256 位密钥（暴力破解成本极高）
- **整个密码库** 用 AES-256-GCM（认证加密）整体加密后存入应用私有目录 `vault.dat`
- 密码错误时 GCM 认证直接失败，无法绕过；密文任何一比特被篡改都会解密失败
- 主密码**不存盘、不可找回**；忘记主密码 = 密码库永久无法解锁（只能重置）
- 锁定时内存中的密钥与明文全部清除

## 四、备份与迁移

设置 → 导出加密备份：把加密后的密码库保存为 JSON 文件。
该文件**本身仍是加密的**（没有主密码无法读取），可以放心放在网盘/微信收藏。
新手机安装 App 后用「导入备份」选择该文件，再用原主密码解锁即可完成迁移。

## 五、常见问题

**Q：忘记主密码怎么办？**
无法找回。解锁界面 →「重置应用」会清空数据并回到创建流程。请务必用 memorable（好记但他人猜不到）的主密码，或把主密码抄在纸质笔记本上妥善保管。

**Q：卸载 App 数据会丢吗？**
会。应用数据随卸载删除，重要密码请定期导出加密备份。

**Q：换手机怎么迁移？**
导出备份文件 → 新手机安装 App → 创建/直接导入备份 → 用原主密码解锁。

## 六、重新构建 / 二次开发

- 项目为标准 Android 工程结构，可直接用 Android Studio 打开（Gradle 文件已就位，无第三方依赖）
- 电脑上也可以用一键脚本重新构建 APK（Git Bash 运行）：`bash build-apk.sh`
  - 依赖：JDK 8+ 与本地 Android SDK（本机已具备）
  - 构建脚本流程：aapt2 资源编译 → javac → d8 → zipalign → apksigner 签名
- 签名密钥在 `build/release.keystore`（口令 passwordshield123）。**今后升级安装请始终用同一个 keystore 签名**，否则手机会要求先卸载旧版

## 七、源码结构

```
PasswordShield/
├─ app/src/main/AndroidManifest.xml
├─ app/src/main/java/com/passwordshield/
│  ├─ MainActivity.java   # 界面与交互（生成/密码库/设置/锁定）
│  ├─ VaultStore.java     # 密码库：整库加解密、增删改、备份
│  ├─ Crypto.java         # PBKDF2 + AES-256-GCM
│  └─ PwGen.java          # 密码生成（SecureRandom 拒绝采样）与强度估算
├─ app/src/main/res/      # 布局、图标、字符串（全部中文）
├─ build-apk.sh           # 一键构建脚本
└─ PasswordShield-v1.0.apk
```
